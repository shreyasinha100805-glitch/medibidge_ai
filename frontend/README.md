# 💊 MediBridge AI — Frontend Application

React 19 + Vite frontend interface for MediBridge AI medication adherence platform.

## Features Included
- 🎵 **Web Audio Alarm Sound Engine** with 4 customizable procedural sound profiles.
- ⏰ **Interactive Alarm Trigger Modal** with dose logging and snooze controls.
- 📷 **AI Prescription Scanner Modal** powered by Gemini 1.5 Flash Vision OCR.
- 📊 **Interactive 7-Day & 30-Day Adherence Analytics**.
- 🌐 **Multilingual i18n support** (EN, ES, HI, BN, FR, SI).

## Local Development
```bash
npm install
npm run dev
```

## Production Build
```bash
npm run build
```
Outputs static bundle to `dist/` ready for Vercel deployment.
